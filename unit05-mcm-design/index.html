地面

  • 卧室：15mm 多层实木 · 胡桃/橡木暖色
  • 客餐：同系列木地板，或大板岩板 800×800 暖灰米
  • 厨卫：防滑瓷砖，橄榄绿腰线点缀
  • 阳台：通体砖，与室内同色系过渡

墙面 / 天花

  • 全屋乳胶漆：暖奶油白，客厅一侧胡桃木护墙板 900H
  • 主卧床头：木饰面或织物软包
  • 天花：平顶留灯槽，客厅局部木梁装饰（非承重）

门窗五金

  • 室内门：胡桃木色平板门，可做圆弧垭口
  • 五金：哑光黄铜把手、合页
  • 窗帘轨隐藏；纱帘米白亚麻

灯光氛围

  • 基础：筒灯 3000K 暖白
  • 重点：黄铜吊灯（餐厅）、弧线落地灯（客厅）
  • 卧室壁灯；柜内灯带 2700–3000K

立面原则：少而精的饰面层次；避免多色碎拼。木、布、铜、石四类材质轮换即可形成中古感。

D-01 施工与改造要点

在保留原结构外壳前提下的可落地改造说明

1. 结构与拆改

  • 北侧入户位置对齐电梯厅兼前室2，玄关深度建议 ≥1200mm
  • 客餐厨可做开放或半开放（玻璃移门），需确认燃气与烟道规范
  • 主卫嵌于主卧东侧，管井就近原则；公卫服务次卧与访客
  • 承重墙以原土建图为准，本图为功能示意，施工前需复核结构

2. 动线

  • 入户 → 玄关收纳 → 餐厅 → 客厅 → 南向阳台，一条主轴
  • 西翼三间卧室串联，夜区安静；东翼厨卫为服务区
  • 半阳2 归属主卧；半阳1 归属客厅观景

3. 机电

  • 中央空调或客厅+三房分体；厨房强排油烟
  • 客厅预留投影/电视双方案；书房强电+网线到桌面
  • 卫浴地暖或定制暖风机；镜柜防雾

4. 中古风落地清单（摘要）

  • 木皮/木饰面占比视觉面约 30–40%
  • 软装绿/黄撞色控制在 15% 以内
  • 黄铜、玻璃、藤编各出现 1–2 件点题即可
  • 避免高光烤漆与冷灰不锈钢作为主材
