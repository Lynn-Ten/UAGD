## 格局摘要

- **两室一厅一卫 + 书房**（书房可改第三卧）
- 北入户玄关 → 西厨 / 中轴客餐厅南向贯通 → 西主卧、东次卧+书房
- 主卧连半阳2，书房连半阳1；卫生间居中便于管线

## 风格要点

- 胡桃木 / 柚木柜体与地板
- 奶油墙面 + 鼠尾草绿软装 + 芥末黄点缀
- 黄铜把手、飞碟灯、圆角与椭圆家具
- 照明统一 **2700–3000K** 暖光

## 重新生成图纸

```bash
python3 generate_drawings.py
```

> 本方案为概念设计图纸，尺寸按原图比例推估。施工图需结合结构、给排水、强电弱电原图与现场实测深化。
